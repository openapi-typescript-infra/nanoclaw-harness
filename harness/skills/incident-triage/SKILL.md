---
name: incident-triage
description: Investigate a reported service incident or health regression using available logs, error tracking, and repository evidence.
---

Anchor the investigation to a time window and affected service. Read the
thread before choosing sources; ask for missing reproduction details only
when evidence cannot resolve them. Group repeated errors by likely cause.

Use installed tools for evidence and include source links or precise file
references in the result. State which observation supports each hypothesis.
If a source is inaccessible, identify the gap rather than inferring health.
End with the next diagnostic or remediation action and its owner if known.
